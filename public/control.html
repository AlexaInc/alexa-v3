👑 Owner & Admin

Status/about/presence, chat & group listings, maintenance mode, task tracking, quiz-pack management, and this Control Panel.

  1. Prepare a MySQL database — group settings, conversation history, and tasks all live in MySQL. Tables are created automatically (CREATE TABLE IF NOT EXISTS) on first connect; you only need empty database credentials.
  2. Clone & install 
    git clone https://github.com/AlexaInc/alexa-v3.git
cd alexa-v3
npm install
    or build the included Dockerfile, which already has every native/system dependency.
  3. Configure environment — copy env_dummy to .env (or set the same keys as PaaS secrets). Minimum required: DB_HOST, DB_PORT, DB_NAME, DB_UNAME, DB_PASS, Owner_nb, bot_nb, ADMIN_USERNAME, ADMIN_PASSWORD, SESSION_SECRET.
  4. Start the bot — npm start runs app.js, the process supervisor that launches and auto-restarts both the WhatsApp connection and this web panel, logging every restart's id/timestamp/reason (shown in the WhatsApp startup message and available in data/restarts.json). Scan the QR code from WhatsApp → Linked Devices.
  5. Log in here — use the ADMIN_USERNAME/ADMIN_PASSWORD from step 3 to reach this Control Panel: live CPU/RAM/network gauges, streaming logs for both processes, and JSON data downloads.
